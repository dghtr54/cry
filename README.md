# 中国10年期实际收益率月度跟踪

每月自动抓取中国宏观数据，基于政策/周期打分模型，估算实际收益率。

## 核心公式
- 估算通胀预期 = 0.5 × 未来1年CPI一致预期 + 0.5 × 12个月核心CPI均值 + 政策修正项
- 估算实际收益率 = 10年期国债收益率 − 估算通胀预期

## 打分规则（每项 ±0.10%，总修正封顶 ±0.5%）
| 分项 | +0.10% | -0.10% |
|------|--------|--------|
| 财政 | 支出-收入同比 ≥ 5pct | ≤ -5pct |
| 地产 | 销售/房价/投资综合分 ≥ 2 | ≤ -2 |
| 信用 | 社融-M2同比 ≥ 1pct | ≤ -1pct |
| PPI | ≥ 0 且高于3个月前 | ≤ -2 且低于3个月前 |
| 汇率 | USDCNY 3M涨幅 ≥ 3% | ≤ -3% |
